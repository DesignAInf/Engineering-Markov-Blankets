# Reference results

These files are the outputs of the full run used in the paper (seed 20260930):

| File | Content |
|---|---|
| `results_v8.json` | E1–E4: equivalence, κ sweep, ρ robustness, threshold, remedies |
| `results_v9.json` | E5–E6: design map, self-engineering |
| `fig1_…fig6_*.pdf` | Figures 1–6 of the paper |

They were generated by the original research scripts from which the `emb` package was
derived. The package was checked against those scripts by running both at reduced sample
sizes with identical seeds: every value in the output JSON files coincided exactly, with zero
differences. A full-size run of the package (`python -m emb.experiments`) therefore
reproduces these files. The only differences are two additions to `results_v8.json → E1`:
a `persistence` block that also reports the aligned agent and system B, and the flat keys
kept for compatibility.

The persistence figures for the aligned agent (26.7 %) and for system B (6.5 %) quoted in
the paper come from that `persistence` block. They are not in the reference `results_v8.json`,
which predates it.
